## Implemented behavior

The desktop now exposes case inputs, structured response editing, approve/return decisions, linked run resumption and specialist acknowledgment. Server-side transactions bind mutations to the current case revision, stable request identity and acting demo presenter. Evidence changes invalidate old drafts; approved content is checked again at execution. Existing sent versions, PDFs and notes remain inspectable.

The agent has scoped task inspection, authorized name-task creation/update and assessed handoff tools. It continues choosing its own tools from evidence. The live evaluator performs explicit synthetic presenter interventions, while the runtime has no scripted scenario sequence or acceptance-oracle access. See [decision 007](../decisions/007-case-workflows.md).
